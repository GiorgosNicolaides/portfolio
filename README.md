# Georgios Nicolaides: Portfolio

Personal portfolio for a DevSecOps & Cloud Security Engineer. Built with Next.js 14 (App Router), TypeScript and Tailwind CSS, and deployed on Vercel.

## Editing content

All site content is in typed data files:

- `data/profile.ts`: headline, summary, stats, skills, timeline, certifications
- `data/projects.ts`: project case studies (problem, solution, metrics, highlights, stack)

Replace `public/George_Nicolaides_CV.pdf` to update the downloadable CV.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```
